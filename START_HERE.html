01

เข้าสู่ระบบและเลือกปีงบประมาณ

ทุกบทบาท⌄

เข้าใช้งานด้วยบัญชีที่ Admin จัดให้ และตรวจปีงบประมาณก่อนบันทึกรายการ

  1. กรอกอีเมลหรือชื่อผู้ใช้ admin และรหัสผ่าน แล้วกดเข้าสู่ระบบ
  2. ตรวจชื่อ บทบาท และหน่วยงานของตนเองทางซ้ายล่าง
  3. เลือกปีงบประมาณด้านบน เช่น 2570 หมายถึง 1 ตุลาคม 2569–30 กันยายน 2570
  4. หากต้องการเรียนรู้ ให้เลือกทดลองใช้งานด้วยข้อมูลตัวอย่างที่หน้าล็อกอิน แถบสีเหลืองหมายถึงข้อมูลสาธิต
ช่อง / รายการกรอกหรืออ่านอย่างไรตัวอย่าง / สิ่งที่ต้องตรวจ
อีเมล / ชื่อผู้ใช้ใช้บัญชีที่ Admin เพิ่มเป็นสมาชิกแล้วเจ้าหน้าที่ใช้ที่อยู่อีเมลของตน
รหัสผ่านตรงตามบัญชีของตนเอง ไม่ส่งให้ผู้อื่นรหัสผ่านเริ่มต้นของบัญชีใหม่อย่างน้อย 12 ตัวอักษร
ปีงบประมาณใช้ พ.ศ. 4 หลัก ให้ตรงเอกสารอนุมัติ2570

ตรวจให้ครบก่อนดำเนินการต่อ
ผู้ที่เพิ่มเป็นสมาชิกใหม่ต้องมีสิทธิ์เข้าชมเว็บไซต์ด้วย จึงจะเข้าถึงหน้าล็อกอินระบบได้

02

ภาพรวม / Dashboard

ทุกบทบาท⌄

อ่านสถานะงบและโครงการก่อนดำเนินการ

  1. เลือกปีงบประมาณ แล้วตรวจวงเงิน จำนวนโครงการ และยอดจ่ายจริง
  2. อ่านกราฟจ่ายจริงสะสมและสัดส่วนการใช้จ่าย
  3. เปิดรายการที่ต้องติดตาม หรือกระดิ่งแจ้งเตือนเพื่อไปยังข้อเสนอ คำขอ และรายงานค้าง
  4. ใช้ส่งออกสรุปเมื่อต้องการนำข้อมูลไปทำตารางต่อ
ช่อง / รายการกรอกหรืออ่านอย่างไรตัวอย่าง / สิ่งที่ต้องตรวจ
งบประมาณทั้งหมดยอดแหล่งเงินในปีที่เลือก; เจ้าหน้าที่เห็นงบจัดสรรของโครงการในขอบเขตตนยังไม่ใช่ยอดเงินที่จ่ายแล้ว
รออนุมัติ / อนุมัติรอจ่ายยอดคำขอที่กันวงเงินไว้แล้วคำขอ 5,000 บาทอยู่ระหว่างพิจารณา
จ่ายจริงแล้วเฉพาะรายการที่บันทึกหลักฐานและวันที่จ่ายแล้ว3,000 บาท

ตรวจให้ครบก่อนดำเนินการต่อ
หน้านี้ไม่ต้องกรอกตัวเลขเอง ตัวเลขมาจากรายการที่บันทึกในเมนูงาน

03

เสนอโครงการ

ผู้จัดทำ / ผู้พิจารณาตามสิทธิ์⌄

จัดทำข้อเสนอให้ครบก่อนส่งพิจารณา

  1. กดเสนอโครงการใหม่ แล้วกรอกชื่อ หน่วยงาน ปีงบประมาณ และงบประมาณที่ขอ
  2. กรอกวัตถุประสงค์แยกบรรทัด พร้อมรายละเอียดความสอดคล้องกับแผน
  3. ระบุวันเริ่ม วันสิ้นสุด และกำหนดส่งรายงาน
  4. เลือกบันทึกฉบับร่าง หรือส่งพิจารณา
  5. ผู้บริหารอีกคนเปิดดู / พิจารณา เลือกอนุมัติ ส่งกลับแก้ไข หรือไม่อนุมัติ
ช่อง / รายการกรอกหรืออ่านอย่างไรตัวอย่าง / สิ่งที่ต้องตรวจ
ชื่อโครงการใช้ชื่อฉบับเต็มตรงตามเอกสารโครงการพัฒนาทักษะดิจิทัล
หน่วยงานรับผิดชอบเลือกส่วนงานหรือสถานศึกษาของผู้รับผิดชอบสำนักพัฒนายุทธศาสตร์และความร่วมมืออาชีวศึกษา
งบประมาณที่ขอตัวเลขมากกว่า 0 ทศนิยมไม่เกิน 2 ตำแหน่ง50000.00
วัตถุประสงค์หนึ่งวัตถุประสงค์ต่อหนึ่งบรรทัดเพื่อพัฒนาทักษะการใช้ระบบงานดิจิทัล
วงเงินอนุมัติ / ความเห็นผู้พิจารณาระบุวงเงินไม่เกินที่เสนอ; ถ้าส่งกลับหรือไม่อนุมัติต้องใส่เหตุผลอนุมัติ 45000.00

ตรวจให้ครบก่อนดำเนินการต่อ
ผู้เสนออนุมัติข้อเสนอของตนเองไม่ได้ เมื่ออนุมัติระบบสร้างโครงการและรหัสให้อัตโนมัติ

04

โครงการ / กิจกรรม

ผู้รับผิดชอบ / ผู้ติดตาม⌄

ตรวจโครงการที่อนุมัติและอัปเดตความก้าวหน้า

  1. ค้นหาหรือกรองสถานะโครงการในปีที่เลือก
  2. เปิดรายละเอียดเพื่อตรวจผู้รับผิดชอบ วัตถุประสงค์ กำหนดส่ง และวงเงิน
  3. กดอัปเดต แล้วกรอกความก้าวหน้า 0–100
  4. จัดทำรายงานผลจากเมนูรายงานและการติดตามเมื่อดำเนินงานแล้ว
ช่อง / รายการกรอกหรืออ่านอย่างไรตัวอย่าง / สิ่งที่ต้องตรวจ
วงเงินอนุมัติเพดานที่ผู้พิจารณาอนุมัติให้โครงการ45000.00
วงเงินจัดสรรเงินที่ Admin จัดสรรให้แล้ว อาจน้อยกว่าเพดานอนุมัติ40000.00
ความก้าวหน้าสัดส่วนผลงานตามแผน ไม่ใช่ร้อยละการเบิกจ่าย60

ตรวจให้ครบก่อนดำเนินการต่อ
การกรอก 100% ไม่ได้ตรวจรับรายงานแทนผู้บริหาร โครงการปิดเมื่อรายงานได้รับการตรวจรับ

ตั้งวงเงินของแหล่งเงินก่อนจัดสรร

  1. กดเพิ่มแหล่งงบประมาณ ระบุชื่อ ปี หมวด และวงเงิน
  2. กรอกเลขอ้างอิงหนังสือจัดสรรหรือรายละเอียดในหมายเหตุ
  3. ตรวจยอดจัดสรรโครงการ ยอดผูกพันส่วนกลาง และยอดยังไม่จัดสรร
  4. ถ้าปรับวงเงิน ให้ใช้ปุ่มปรับวงเงินและระบุเหตุผล

ชื่อแหล่งงบประมาณระบุให้แยกจากแหล่งอื่นได้ชัดเจนงบพัฒนาคุณภาพการจัดการอาชีวศึกษา

หมายเหตุ / เหตุผลใช้ติดตามเอกสารอ้างอิงและการปรับยอดตามหนังสือจัดสรรเลขที่ …

ตรวจให้ครบก่อนดำเนินการต่อ
ปรับลดต่ำกว่ายอดจัดสรรและภาระผูกพันที่มีอยู่ไม่ได้

  2. เลือกโครงการที่อนุมัติแล้วและยังดำเนินงานอยู่
  3. เลือกแหล่งเงินในปีงบประมาณเดียวกัน
  4. กรอกจำนวนเงินและหมายเหตุ แล้วบันทึก

07

คำขอเบิกจ่าย

ผู้ขอ / ผู้พิจารณาตามสิทธิ์⌄

ขอใช้จ่ายจากงบที่จัดสรรให้โครงการ

  1. กดสร้างคำขอเบิกจ่าย แล้วเลือกโครงการ
  2. เลือกแหล่งเงินที่จัดสรรให้โครงการนั้น
  3. กรอกรายการ / วัตถุประสงค์และจำนวนเงิน ตรวจยอดใช้ได้ แล้วส่งคำขอ
  4. ผู้บริหารอีกคนเปิดรายละเอียดแล้วอนุมัติหรือไม่อนุมัติ
ช่อง / รายการกรอกหรืออ่านอย่างไรตัวอย่าง / สิ่งที่ต้องตรวจ
โครงการ / แหล่งเงินต้องมีงบจัดสรรไว้แล้วโครงการพัฒนาทักษะดิจิทัล / งบดำเนินงาน

ตรวจสถานะได้ด้วย SQL แบบอ่านอย่างเดียว:

select tablename, rowsecurity
from pg_tables
where schemaname='public'
  and (tablename like 'pm\_%' escape '\' or tablename='andaman_project_reports')
order by tablename;

select id, public from storage.buckets
where id in ('andaman-pm-files','andaman-report-photos');

ตรวจ Supabase จริงแบบอ่านอย่างเดียวตามหัวข้อ 1; ไม่แก้ฐานข้อมูล บัญชี รหัสผ่านหรือ Secrets จริงในการจัดชุดนี้ และไม่ได้ Push เข้า GitHub ของคุณโดยตรง คุณต้องนำชุดไป Commit/Push และ Deploy บริการที่ระบุ แล้วทดสอบบัญชีจริงตามหัวข้อ 14

ภาพไม่เกิน 20 ภาพต่อรายงาน ภาพละไม่เกิน 1.5 MB และภาพกิจกรรมรวมส่งสำเนาไม่เกิน 9 MB เซลล์ชีตเก็บข้อความไม่เกิน 49,000 ตัวอักษร ร่างในเครื่องไม่ย้ายข้ามโดเมนโดยอัตโนมัติ ให้บันทึกออนไลน์หรือส่งออก JSON ก่อนย้ายเครื่อง

S.D. เป็นส่วนเบี่ยงเบนมาตรฐานของตัวอย่างจากความถี่คำตอบที่กรอก ภาพรวมรวมคำตอบทุกข้อ ไม่ใช่ S.D. ของคะแนนเฉลี่ยรายบุคคล เพราะไม่มีคำตอบรายคน ข้อไม่มีคำตอบใช้เครื่องหมาย — และไม่สร้างผลขึ้นเอง
