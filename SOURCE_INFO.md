# Source provenance

Report UI based on the existing Andaman ProjectPM report editor at commit
edb91a8d9a2ebf32bae7809b786feaddbd6dc26d (2026-10-26).

This is a separate Apps Script delivery. It does not alter the existing source
repository, published site, GitHub repository, Google account, or Supabase schema.
The generated Index.html and Core.gs can be rebuilt with npm run build.
Public configuration for ANDAMAN2-PM is in apps-script/Config.html.
All credentials that grant privileged access must be supplied in server settings.
